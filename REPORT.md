## 2. Відповідь на контрольне запитання

**Запитання:** Що таке регулярні вирази і для чого вони використовуються?

**Відповідь:**

Регулярні вирази (Regular Expressions або RegEx) — це спеціальна мова шаблонів (патернів), яка використовується для пошуку, валідації, редагування та маніпуляції з текстом. 

У Python для роботи з ними використовується модуль `re`. Регулярні вирази потрібні для:
- Валідації даних (наприклад, перевірка чи введений номер телефону відповідає формату `+380...`).
- Пошуку підрядків зі складною логікою (наприклад, пошук усіх email-адрес у тексті або версій програмного забезпечення).
- Заміни та форматування частин тексту (заміна множинних пробілів на один, видалення спецсимволів тощо).
